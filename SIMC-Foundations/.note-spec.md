## THE REPORT (ground truth — make every "why this matters" accurate to this)

Title: "A Linear-Algebra Guide to the Strange Life of High-Dimensional Data", SIMC 2026
Endeavour, Team SIMC10. Three questions:

**Q1 — Markov matrices & the fate of a population.** Populations $p_1(t),p_2(t)$ evolve by
$P(t+1)=MP(t)$, $M=\begin{pmatrix}1-\varepsilon&0\\\varepsilon&1\end{pmatrix}$, $\varepsilon\in(0,1)$. Type-1 converts to type-2 at rate $\varepsilon$, nothing returns.
- (a) Total $S=p_1+p_2$ is conserved ($\varepsilon$ terms cancel; equivalently columns of $M$ sum to 1 → column-stochastic → $\mathbf 1^\top M=\mathbf 1^\top$).
- (b) $M$ lower-triangular → eigenvalues = diagonal: $\lambda_1=1,\ \lambda_2=1-\varepsilon$. Eigenvectors $v_1=(0,1)$ (all type-2), $v_2=(1,-1)$ (transient).
- (c) Write $P(0)$ in the eigenbasis: $P(0)=c_1v_1+c_2v_2$, $c_1=S(0)$, $c_2=p_1(0)$.
- (d) Closed form: $M^tv_i=\lambda_i^tv_i$ so $P(t)=c_1v_1+c_2(1-\varepsilon)^tv_2$.
- (e) Long run: $(1-\varepsilon)^t\to0$, so $P\to c_1v_1=(0,S(0))$: all mass becomes type-2. $v_1$ is the absorbing steady state.
- (f) Numerical check: iterate vs closed form agree to $10^{-16}$.
- (g) Time-varying rate $\varepsilon(t)=\varepsilon_0e^{-t/t_0}$: $M(t)$ differs each step BUT shares eigenvectors. The transient mode collects one factor $(1-\varepsilon(s))$ per step → an infinite **product** $\prod_s(1-\varepsilon(s))$, NOT a power $(1-\varepsilon)^t$. The product converges to $\Pi_\infty>0$ (since $\sum\varepsilon(s)<\infty$), so type-1 is never fully depleted: a permanent residue $c_2\Pi_\infty$ freezes in the $v_2$ direction.
- (h) Numerical check of (g); residue $\approx10^{-3}$.

**Q2 — The power method & the SVD.** $X$ symmetric $n\times n$, eigenvalues $|\lambda_1|>|\lambda_2|\ge\cdots$, orthonormal eigenbasis. Power method $x_{k+1}=Xx_k/\lVert Xx_k\rVert$.
- (a) Converges to $\pm v_1$ (dominant eigenvector) if $x_0$ has a $v_1$ component. Proof: expand $x_0$ in the eigenbasis; the $v_1$ term dominates because $(\lambda_i/\lambda_1)^k\to0$.
- (b) Convergence is geometric at rate $|\lambda_2/\lambda_1|$ — the **spectral gap**. Wide gap = fast/stable; narrow = slow/fragile.
- (c) When the gap closes ($|\lambda_1|=|\lambda_2|$): structural failure. $X=\mathrm{diag}(1,-1)$ → iterate oscillates forever, never converges. Near-degenerate: iteration count $\sim1/(1-|\lambda_2/\lambda_1|)$; per-step separation shrinks to the $10^{-16}$ rounding level → eigenvalue ordering ambiguous.
- (d) For general $m\times n$ $X$: both $X^\top X$ ($M\times M$) and $XX^\top$ ($N\times N$) are symmetric and **positive semi-definite** ($w^\top(X^\top X)w=\lVert Xw\rVert^2\ge0$). They share nonzero eigenvalues (if $X^\top Xv=\lambda v,\ \lambda\ne0$, then $Xv$ is an eigenvector of $XX^\top$ with the same $\lambda$). $\sigma_i=\sqrt{\lambda_i}$ are the singular values.
- (e) Power-method SVD: build the SMALLER square ($d=\min(N,M)$) — $XX^\top$ if $N\ll M$, else $X^\top X$ — iterate to the top eigenvector, $\sigma_1=\sqrt{\lambda_1}$ (Rayleigh quotient), partner vector via one more product. Worked $3\times2$ example $X=[[1,0],[0,1],[1,1]]$: $X^\top X=[[2,1],[1,2]]$, $\lambda=1,3$; $\sigma_1=\sqrt3$, $v_1=(1,1)/\sqrt2$, $u_1=(1,1,2)/\sqrt6$.

**Q3 — Cleaning, PCA, clustering of IR spectra.** $X\in\mathbb R^{N\times M}$, rows = samples (vials), cols = features (frequency channels). File loads as $3401\times1000$, stored transposed (transpose → rows=samples); prompt said $M=3041$ but file has 3401 (digit transposition) — used the true 3401.
- (a) Clean by Euclidean row-norm: 40 empty vials (tiny norm $\approx1.6$, background noise) below a clean gap, threshold stable for any cut in $[2.0,4.0]$. Plus 36 high-norm outliers ($\approx8.9$), kept as a Boolean mask (non-destructive) → $\tilde N=924$. The 36 form one isolated cluster.
- (b) Mean-centre each feature. Covariance $C=\frac1N\tilde X^\top\tilde X\in\mathbb R^{M\times M}$; diagonal = feature variances; symmetric; $\operatorname{tr}C=\sum\mathrm{Var}_j$ = total variance = $\sum\lambda_i\approx7.90$ (invariant under orthonormal change of basis). Most-variable feature $j^*=910$.
- (c) Eigenspectrum via `np.linalg.eigh` (symmetric solver; clip rounding-level negatives to 0). $\lambda_1/\lambda_2\approx3.5$; $\lambda_1\approx31\%$ of total. Elbow $k^*=8$ = largest multiplicative drop $\lambda_8/\lambda_9\approx4.1$. But the bare elbow is NOT bootstrap-stable. "95% rule" misleading (needs 667 components). Robust intrinsic dimension = **participation ratio** $d_{\text{eff}}=(\sum\lambda)^2/\sum\lambda^2\approx8.7$, bootstrap CI $[7.6,10.0]$.
- (d) Leading eigenvector $v_1$: loadings concentrate on two narrow bands, ~27% negative → a **contrast/difference** direction, not overall brightness. $\cos(v_1,\text{centred spectrum})\approx0.92$ (scale-free cosine similarity).
- (e) Project onto top-4 eigenvectors: scores $Z=\tilde XV_4\in\mathbb R^{\tilde N\times4}$. Leader clustering with radius $r$ → **25 clusters**, stable for $r$ in ~$[6,12]\times$ median nearest-neighbour spacing.
- (f) Gram matrix $G=\frac1N\tilde X\tilde X^\top\in\mathbb R^{\tilde N\times\tilde N}$ (sample space). Since $\tilde N=924\ll M=3401$, diagonalising $G$ costs $(M/\tilde N)^2\approx13.5\times$ less ("use the smaller square", Q2e). Shares nonzero eigenvalues with $C$ (Q2d duality); top-8 agree to $10^{-6}$. Same 25 clusters.
- (g) Covariance and Gram clusterings coincide necessarily: SVD $\tilde X=U\Sigma V^\top$, covariance scores $Z=\tilde XV=U\Sigma$, Gram scores $Z_g=U\sqrt{\tilde N\lambda}=U\Sigma$ — same matrix up to per-axis sign. So $25=25$.
- (h) Synthesis: $\approx25$ unique food samples (924 genuine spectra = 25 tight clusters of ~37 replicate vials; $24\times37+36=924$). Intrinsic dim $k^*=8\approx$ the ~10 dominant molecules. **Eckart–Young**: top-$k$ projection is the best rank-$k$ approximation (min Frobenius error $\sum_{i>k}\sigma_i^2$), so keeping 8 components is optimal compression (~55% variance, 425-fold reduction).
